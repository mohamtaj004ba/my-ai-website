# Phone-search workflow technical review

This is a Work-authored extension of the existing workflow, not a phone-search product correction. CallerCore's Specialist must author the real patch. Main, Production and internal-agent publication authority are unchanged.

## Scope and compatibility

The server-owned task manifest determines files and exact replacement sites. The phone assignment covers Calls, Contacts, Follow-ups, local Conversations and backend-paged Conversations. Unchanged historical single-file contracts remain replayable. Both original source preimages are immutable authenticated data; current-source admission independently verifies actual source. No extra backend source read grant was added to restricted workers.

## Findings addressed

- Ordinary worker failure could leave a preparation marked started despite physical disposal. Confirmed cleanup now propagates after deletion; the actual broker fault test verifies destroyed journal state, revoked grants and preserved usage.
- New policy was absent from additional-authorization accounting recognition. Coordinated policy/serial/UI registration fixes recognition without altering historical accounting or reviving consent.
- Source code and assertions shared a guest process. OS isolation alone did not prevent generated expressions reaching host constructors and forging test output. A reviewed static AST grammar now blocks capability reachability before native acceptance and test-program generation. No arbitrary generated-JavaScript execution is authorized.
- New syntax failures were becoming unknown diagnostics. Closed codes, field paths and the pure-expression rule now survive native failures without rejected code, secrets or raw exception messages.
- A single fictional caller could permit fixture-specific behavior. Tests now use different names, US/UK numbers, text controls, false positives and backend cursor behavior.

## Parser provenance

The unchanged official Acorn 8.19.0 CommonJS distribution is under `lib/vendor`, together with its MIT license and exact SHA-256/byte metadata. The official npm archive SHA-512 was independently verified before extraction. No package scripts ran. This isolated vendored dependency avoids unnecessary changes to frozen application dependency/source manifests; it remains covered by release hashing, tests and security review. [Official parser documentation](https://github.com/acornjs/acorn/tree/master/acorn).

All model and VM outcomes in these tests are explicitly synthetic. Fixtures do not establish live model quality, product acceptance or browser behavior.

The two independent Work reviewers recommend feature Preview publication for normal qualification. They do not confer human acceptance, Production release, arbitrary execution or internal-agent publication authority. Paid execution stays disabled until applicable release gates pass.
